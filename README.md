# 企业情报研究助手

面向企业战略、市场与行业研究人员的研究工具，围绕单家公司、时间范围和主题整理资料，经过人工审核后生成带来源的简报。

当前为 **V0.6 桌面端本地交互原型**。已支持创建任务、自动搜索与网页正文读取、手动录入、本地 PDF/TXT/Markdown 导入、URL 与文件重复提示、人工审核、本地资料库、带匹配上下文的关键词检索复用、规则摘录、引用查看、Markdown 导出和本地调用记录。独立事件提取、内容相似度去重及向量语义检索尚未实现。

界面采用“来源与状态”方案：顶部四步导航、统一研究范围栏、并排的资料列表与原文。示例体验通过顶栏入口展开独立右侧栏，默认收起，主界面只保留正式研究流程。当前仅面向桌面浏览器，建议窗口宽度至少 1120px；已移除手机端专属布局、按钮和交互。资料编号在审核、简报及导出中保持对应。设计使用 [Impeccable](https://github.com/pbakaus/impeccable) 的流程和审查规则，代码由本项目实现。

## 本地运行

安装 Node.js 22.13 或以上版本，在项目目录执行：

```powershell
npm ci --omit=optional
npm start
```

打开终端显示的地址，默认是 http://127.0.0.1:4173 。首次运行需安装锁定的 PDF.js 依赖；文件解析组件由本地服务提供，不依赖 CDN。保持服务运行，按 Ctrl+C 停止。

点击顶栏“示例体验”，再在侧栏中点击“载入示例任务”，可载入 5 条自主编写的虚构资料，包括未知日期、范围外和无正文的情况。示例公司和事件均为虚构，不代表真实企业动态。也可以创建自己的任务并手动录入来源和原文片段。

当前任务、保存正文和审核选择保存在本机浏览器的 localStorage；明确入库的资料另外保存在本地服务的 `data/library.json`，不随清空或替换当前任务删除。没有任务历史或云端同步。报告需要在刷新后重新生成。清空或替换任务前会提示确认，请及时导出简报。只有点击搜索或读取操作才会请求资料服务，手动录入链接本身不会触发访问。

## 本地资料库与关键词 RAG

人工审核并纳入有正文的正式资料后，在资料详情点击“保存到资料库”。纳入本次简报与入库是两个独立操作；不会自动归档全部资料。虚构示例、未纳入资料和已经检索得到的片段不能再次入库。待核实资料可以明确保存，但核查备注、标记、日期与截取问题会一并保留。

顶栏“资料库”可在没有当前任务时浏览、筛选公司、查看保存正文和撤回资料。资料保存在运行本地服务的电脑上，不是浏览器缓存；请自行备份 `data/library.json`，原 PDF 等二进制文件仍需另外保管。该目录已被 Git 忽略。可以用环境变量 `LIBRARY_PATH` 指定其他本地文件位置；服务启动后修改配置需重启。当前采用带版本的 JSON 文件、原子替换及同一进程内串行写入，面向单个本地服务使用，不支持多个服务进程同时写同一个库。最多 200 份资料、每份 20 个版本、文件 32 MiB。

收集页可“从资料库检索”，按当前公司的完整名称匹配，在保存正文中检索相关片段；公司别名不会自动合并。默认不检索有待核实提示或已撤回的资料，可主动开启“包含待核实资料”。可选日期筛选针对**资料发布日期**，不等同于业务统计期间；日期未知的资料不会通过已设日期范围。查不到应调整检索词或补充资料，不能据此断定相关事实不存在。

采用中文相邻字与英文词的关键词匹配，每个容器片段最多约 900 个 UTF-16 字符、相邻段约 100 字符重叠，单次最多返回 8 个结果。V0.5.1 围绕匹配位置显示最多 480 字符的连续原文上下文，并安全高亮命中词；可展开原容器片段和入库原文核查。点击加入时保存的是页面显示的匹配上下文，实际字符位置随引用保留，加入后仍待审核。同一容器中不同且未被已存上下文覆盖的内容可以另行加入。

这仍是关键词 RAG，没有 embedding、向量数据库或语义重排。检索与资料库操作无需 API 密钥，不访问外部模型；加入前服务会复核资料仍可用且版本未变。DeepSeek 生成仍仅发送纳入文本并可能计费。短上下文可能遗漏同文档另一处重要口径，需展开原文并补充相关片段，不能把高亮当作完整答案。旧任务中超过 500 字符的库内片段，规则摘录也按查询选择上下文，保存的来源快照不被改写。

同一公司下，相同规范化 URL，或相同文件 SHA-256 与 PDF 选页范围，视为同一资料；无链接的手动资料按原资料 ID 识别。相同正文与审核元数据重复保存不新增版本，内容或审核元数据改变后保存为新版本。撤回仅停止后续检索，历史资料和已有任务、报告中的依据快照继续保留；撤回不是永久删除。更新或撤回不会回写旧报告；过期检索结果需重新检索。多个同源片段不构成多个独立证据。

引用和 Markdown 记录资料库文档 ID、版本、片段 ID、保存文本字符位置、检索词、检索时间以及入库时提示，并继续保留文件名、PDF 选页、来源链接与备注。字符位置对应当时保存文本，不是原 PDF 内的精确坐标。入库只保存已审核的文本快照，不能补回先前截取、未提取的内容，也不证明原资料真实。资料库基础验证见 [V0.5 记录](docs/verification-v0.5.md)，本轮范围见 [V0.5.1 验证](docs/verification-v0.5.1.md)。

## 固定资料检索评估

V0.5.1 使用蔚来和小鹏汽车六份官方正文、14 个固定问题完成对照：11 个正例及 3 个无答案控制。原文只在本地被忽略的输出目录保留，仓库保存来源清单、指纹、标注和离线评估脚本。运行 `npm run eval:retrieval`；首次缺少原文时需明确执行 `npm run eval:retrieval -- --fetch`，网页变化会停止，不自动改写标签。

本组题目中，最终首位和前五容器命中均与基线相同；预览完整覆盖从 1/11 变为 9/11，其中显示预算由 180 增至 480 字符解释了大部分收益，同为前 480 字符的基线控制为 8/11。规则摘录完整覆盖仍为 9/11，无答案问题仍有 2/3 返回相关词片段；不是模型事实准确率。实验排序首位命中退化，已放弃并保留原排序。该题集参与版本选择，不能当作独立留出测试；没有真实模型答案、效率对照或泛化结论。详见 [评估表、失败案例与前后对照](docs/retrieval-evaluation-v0.5.1.md)。

## 自动搜索与网页读取

配置现有 `DEEPSEEK_API_KEY` 并重启服务后，在“收集资料”页点击“搜索并读取正文”。系统按公司、主题与日期生成可修改的检索词，通过第三方 DeepSeek Search 搜索最多 5 条候选，再逐条调用 DeepSeek Fetch 读取公开网页为文本。也可粘贴单个公开网页链接，点击“读取网页”。两类接口复用模型密钥，不需要新增前端凭据。接口能力与计费参考 [DeepSeek 搜索与抓取说明](https://api-docs.deepseek.com/zh-cn/guides/search/)。

检索词与所读取的链接会发送至 DeepSeek，搜索、读取及简报生成可能分别产生费用；没有自动付费重试。搜索摘要单独显示，不能充当保存正文。读取成功、失败和待读取状态逐条保留；失败可重试，停止会保留已经完成的资料，刷新后可继续读取。再次搜索会跳过已有的规范化 URL，不覆盖原正文或审核选择；尚无内容相似度去重。

自动资料默认待审核，无正文不能纳入。来源名称、日期来自搜索元数据或网站域名，日期可能与正文、时区或实际发布日期不一致；检索条件不保证覆盖或精确过滤。进入审核后展开“核实来源信息与备注”，对照原文修正来源与日期、记录口径差异，再选择纳入或排除。未知日期请留空，不使用收集时间代替。

每条结论的相关来源若被标记待核实，或存在未知日期、范围外日期、截取和未核实搜索日期等提示，程序会在页面及 Markdown 附加来源提示；完整备注保留在对应来源区，避免依赖模型是否复述标记。提示只能说明来源需核查，不能证明结论真伪。

正文最多保存 12,000 字，超限明确记录原提取字数与截取；服务响应限制 2 MiB、单次超时 30 秒。扫描件、需登录、动态加载、站点访问限制和部分 PDF 可能无法读取，可使用本地文件导入。应用只请求固定的 DeepSeek 服务接口，不向目标站点发送本地密钥、浏览器 Cookie 或登录信息；本机、内网后缀、IP 地址、非默认端口和带账户信息的链接会被拒绝。第三方 Fetch 的结果仍需核对，不宣称自研网页解析器或绕过访问限制。

## 从本地文件导入

在“收集资料”页点击“导入本地文件”，逐个选择 PDF、TXT 或 Markdown（.md），单个文件不超过 10 MB。文件在浏览器内提取文字，原文件不会上传或保存到服务器。

PDF 可选择起止页码，每次最多提取 100 页；先预览并编辑正文，再补充标题、来源名称、发布日期和可选原文链接。不要把文件修改日期当作资料发布日期。TXT/Markdown 支持 UTF-8、GB18030 以及带 BOM 的 UTF-16。扫描版 PDF 暂不支持 OCR，受密码保护的 PDF 需先解密。

单条保存文本上限仍为 12,000 字。超过时只预填前 12,000 字，并保留截取提示；可改选相关 PDF 页码后重新提取。保存后的资料默认为待审核，同一文件及相同 PDF 页码范围会提示重复候选。原文件名、SHA-256 指纹、页码范围和截取情况随资料保存，并进入报告及 Markdown 引用；浏览器仅保存元数据与选定文本，原 PDF 请自行保管。

本地导入不调用模型或正文服务。之后选择 DeepSeek 并点击生成时，纳入的保存文本才会发送至模型服务。PDF 文字顺序、表格和日期仍需对照原文核查；当前没有批量文件导入、OCR 或 Word/Excel 解析。

## 可选：配置 DeepSeek

将 `.env.example` 复制为 `.env`，在本机填写 `DEEPSEEK_API_KEY`，并按开放平台账户可用模型设置 `DEEPSEEK_MODEL`，重启服务。参考 [DeepSeek 官方接入说明](https://api-docs.deepseek.com/zh-cn/)。密钥仅由本地服务读取，`.env` 已被 Git 忽略，不要在聊天、代码或提交中粘贴密钥。

配置后可在简报页选择 DeepSeek。用户点击生成时，纳入的资料正文会发送到 DeepSeek API，可能产生服务费用。未配置时可使用“规则摘录”，不会调用模型。当前摘要请求使用非思考模式、6,000 tokens 输出上限，并要求最多 12 条简短结论；截断、空正文、JSON 或引用校验失败分别提示，不自动重试。

DeepSeek 生成请求仅提交已审核纳入且有可用正文的资料，纳入正文总量上限为 80,000 字，超过时会在提交前提示。待审核和已排除资料继续保留在当前任务，引用编号保持对应。服务端同时只处理一份模型简报，其他并发生成请求需稍后重试。

已通过浏览器界面完成首个小米真实案例：导入三份季度公告第 6 页、核对末页发布日期、审核纳入、真实调用、引用查看和 Markdown 导出。首次生成失败后定位到输出长度上限，修复后两次成功；最终 12 条结论均在关联保存文本中找到依据，但 YU7 的 5 月/6 月表述差异未被模型主动汇总，结论级待核实标签仍有遗漏。此结果不代表真实事实审计、普遍准确率或完整 P0 验收；费用基线尚未建立。详见 [V0.3.1 真实案例验证](docs/verification-v0.3.1.md)。

V0.4 新增一次自动收集案例：真实搜索 5 条、读取成功 5 条，人工式审核纳入 2 条转载资料并更正日期、记录同源限制，真实生成并导出。最终 5 条结论均附有程序生成的来源待核实提示；模拟响应另行验证模型漏写标签时仍会显示提示。结果仍有主题偏移和概括粒度问题，不代表独立交叉验证、完整前三季度覆盖或一般准确率，详见 [V0.4 验证记录](docs/verification-v0.4.md)。

引用 ID 检查只能识别缺失、未知或不属于纳入资料的引用；无法自动证明结论被正文支持，仍需要人工核查。普通资料规则摘录最多 500 字符；库内旧长片段按查询选取最多 480 字符，新增匹配上下文不超过此上限。时间线按资料发布日期整理。

## 本地调用记录

顶栏“调用记录”可独立查看本机服务发起的 DeepSeek 搜索、网页读取和简报生成。支持仅当前任务、操作与状态筛选、刷新和导出当前列表为 JSON；清空或替换任务不会删除记录。每次外部请求有独立调用 ID，通过响应头 `X-Call-Id` 返回；读取网页另保留任务与资料 ID，手动重试作为新调用记录，不自动重试。规则摘录、文件导入和资料库检索不产生外部调用记录。

记录状态包括进行中、成功、失败、已取消和未完成；同时保留开始/结束时间、请求处理耗时、模型、服务方 HTTP 状态/请求 ID、可获得的输入/输出/总 token 与缓存用量，以及固定错误编号。用量字段按 [DeepSeek Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/) 映射，仅保存服务方实际返回的非负整数；缺失显示未知，返回的 0 保留为 0。耗时包含记录准备、服务响应和结果校验，并非独立的模型推理耗时。来源校验失败也会记为失败，已返回的用量仍保留。

费用统一为未知，尚未接入账单、定价估算或费用汇总。取消会请求中断上游连接，但不能证明服务方没有执行或计费；服务重启时此前未完成的记录标为未完成，不推算结束耗时、用量或费用。软件实现已用合成服务验证，本轮未开展真实付费调用或建立账单基线。

数据默认保存在被 Git 忽略的 `data/calls.json`，可通过 `CALL_LOG_PATH` 更改并重启服务生效。采用串行原子写入，仅面向单个本地服务进程；最多保留最近 500 条，达到上限优先移除旧的已结束记录并保留进行中记录，请及时导出。记录只保留调用元数据，不保存资料正文、研究问题/检索词、网页链接、模型输出或密钥。文件损坏不会被自动覆盖；无法建立初始记录时不发起外部请求，结束状态保存失败会保留返回结果并提示，避免将记录失败误当成需要重新付费调用。已有历史调用不能补录。

## 验证

```powershell
npm test
```

浏览器回归需要 Playwright，可使用已有安装，或执行 `npm install --no-save --package-lock=false playwright` 后运行 `npm run test:browser`。脚本优先使用 Windows 默认路径下的 Chrome；其他路径可通过 `CHROME_PATH` 设置，也可使用 Playwright 自带浏览器（需另行安装）。

浏览器回归脚本会启动独立测试服务，使用虚构数据和模拟模型响应，结束后停止测试服务；截图及导出结果写入被 Git 忽略的 `outputs/`。`npm run test:library-browser` 单独验证资料库，`npm run test:retrieval-browser` 验证匹配上下文和精确导入，`npm run test:calls-browser` 验证调用记录、用量、筛选/导出、重试与取消，均使用临时数据文件，不写正式 `data/`。本轮没有真实付费调用。V0.4 的真实自动收集记录保留在 [V0.4 验证记录](docs/verification-v0.4.md)，最新范围见 [V0.6 验证记录](docs/verification-v0.6.md)。

# V0.4 自动收集与来源提示验证

- 日期：2026-10-29，北京时间。
- 目标：从研究范围自动搜索、读取公开资料，经人工审核生成带引用简报，并让来源提示不依赖模型是否复述。
- 操作者：Codex 在用户指导下辅助实现和操作；不是目标用户访谈或独立事实审计。
- 环境：Windows、Node.js 22、原生网页与本地服务。通过浏览器专用控制实际填写表单、点击搜索/读取/审核/生成/下载，没有注入任务状态或伪造真实服务结果。
- 隔离：真实测试使用本机 4174 端口，虚构回归使用 4176；原有 4173 浏览器任务和原始文件未被清空。完整原文与输出仅保存在被忽略的 `outputs/v0.4/`。

## 实现与第三方边界

按 [DeepSeek Search/Fetch 文档](https://api-docs.deepseek.com/zh-cn/guides/search/) 接入固定的 `/v1/tools/search` 与 `/v1/tools/fetch`，复用服务端本机密钥。Search 只获取候选与摘要，`need_content=false`；Fetch 按 URL 返回页面的 Markdown 文本。搜索、读取和模型生成可能分别计费，本轮没有取得账单，不能宣称免费或给出实际费用。

本项目实现查询组合、服务适配、状态管理、来源核查、错误与重试、引用及导出；网络搜索和正文处理由第三方提供，不宣称自研搜索引擎或网页解析器。Fetch 可能转换图表、图片或排版，保存的是服务实际返回文本，不能假定完全还原原网页。

单次最多 5 条候选；已有 URL 跳过，不覆盖保存内容或审核选择。资料总数仍最多 40 条。每条正文最多 12,000 字，保留原提取字数和截取标记；服务响应最多 2 MiB，单次超时 30 秒、本地收集请求同时最多 2 个。应用只请求固定 DeepSeek 接口，不直接访问任意目标 URL；拒绝本机、内网后缀、IP、非默认端口和含账户信息的链接，目标站点的进一步访问策略由第三方 Fetch 执行。

## 真实小米端到端案例

任务：小米集团，资料日期范围 2025-01-01 至 2025-11-18，主题为“2025年前三季度汽车交付、智能电动汽车收入、销售网络与YU7进展”。检索词由规则组合公司、主题和扩展一天的日期边界，未经模型生成；用户可以修改，最多 128 个 Unicode 字符。日期条件不能保证搜索元数据或结果覆盖准确。

一次真实搜索返回 5 条候选，随后 5 次 Fetch 均成功；每条资料先保存为待审核，不自动纳入。

| 资料编号 | 返回并读取的页面 | 实际保存字数 | 本次审核 |
| --- | --- | ---: | --- |
| 1 | [北京日报上的小米 Q3 业绩发布稿转载](http://xinwen.bjd.com.cn/content/s691c45d6e4b0221b9befc85b.html) | 3,035 | 纳入；对照正文修正来源、日期并标待核实 |
| 2 | [我的钢铁网上同题业绩转载](https://m.mysteel.com/a/25111914/23877467FF191615_abc.html) | 3,337 | 排除；与已有资料重复，同源转载不作为独立证据 |
| 3 | [成都商报相关报道](https://cdsbrss.cdsb.com/toutiao_no_video.php?url=https%3A%2F%2Fstatic.cdsb.com%2Fmicropub%2FArticles%2F202511%2F3e58a8a4c175ac2922c4863f2979ec3b.html) | 2,135 | 排除；本轮不扩展股价和手机业务分析 |
| 4 | [新浪财经研发投入报道](https://finance.sina.com.cn/stock/s/2025-11-19/doc-infxwekq5181629.shtml) | 2,851 | 排除；不是本轮核心汽车业务来源 |
| 5 | [证券之星转载汽车之家 Q3 报道](https://4g.stockstar.com/detail/IG2025111800028474) | 945 | 纳入；对照正文修正日期、注明转载及财务口径 |

合计保存 12,303 字，各条均未达到正文截取上限。不能把 5 次成功读取推广为一般站点读取成功率，也不能把 5 条候选当作独立证据。

实际发现：

- 资料 1、5 的初始搜索日期均显示为 2025-11-17，保存正文分别标注 2025-11-18 18:09 和 17:54:45。通过“核实来源信息与备注”按正文改为 11 月 18 日，明确记录差异；服务元数据可能存在时区或站点差异，不能据此直接判断原站错误。
- 部分来源名称初始为编码串；适配器已对明显十六进制形式回退显示域名，仍保留人工修订入口，不推断真实发布者。已纳入来源按保存正文署名修正；未纳入资料仍作为未经确认的候选记录。
- 搜索结果集中于 Q3 新闻/转载；有些 URL 或正文涉及 11 月 19 日，不能因检索词写了日期就认定均在范围内。人工审核和来源提示仍不可省略。
- 两个纳入来源都引用同一公司业绩披露；转载及转引不构成独立交叉验证，也没有直接取得原始官方公告 PDF。

通过真实模型生成两次并从页面下载两版简报：首次 11 条，最终 5 条。点击至报告生成时间戳分别为 4.486 秒与 2.440 秒；搜索点击至最后一条正文读取时间戳为 30.649 秒。这些是含本地开销的时间差，不是供应商纯推理耗时或效率对照。最终 5 条均有关联来源 1、5，5 条均附加程序生成的来源待核实提示；来源编号不因排除中间资料重排。页面引用、保存文本、来源备注与 Markdown 均保留，排除的 2、3、4 未进入模型依据或报告来源。

本轮最终输出主要包含 Q3 交付/分部收入、门店网络、YU7 排名，另有集团财务与研发内容，存在主题偏移；没有完整列出 Q1/Q2 的收入、交付和网络比较。“首次单季盈利”的主体和指标仍应对照分部披露核查，不把它当作汽车业务净利润。本文只确认流程和来源可追溯，不能宣称最终报告全部事实通过独立审计、搜索覆盖完整或普遍准确率提升。

## 确定性的来源提示

`claimSourceWarnings()` 从报告的纳入来源快照和每条结论的引用 ID 计算提示，页面与 Markdown 使用同一规则。人工标记、未知/范围外日期、截取和未核实搜索日期均保留；核查备注在对应来源区单独出现，避免在每条结论下重复长备注。

模拟模型专门返回不含“待核实”的正文，界面仍显示来源提示，导出使用相同规则；不是依赖本轮真实模型恰好输出了标签。提示说明来源需核查，不代表模型事实已被判定错误，也不会自动解释 YU7 等事件的表述差异。

## 自动检查

`npm test`：32 项通过。新增覆盖：

- Unicode 检索词预算和日期边界；候选待审核、摘要不能充当正文、规范化 URL 去重及 40 条容量限制。
- 网页元数据结构、正文与读取状态、不可用正文禁止作为依据、重读保留排除与备注，旧的纳入审批在文本改变后失效。
- 模型漏标签时逐条产生来源提示，Markdown 保留备注/读取/日期来源；报告来源和结论快照不被后续修改污染。
- 本机、内网、IP、账户信息、非默认端口及危险协议拒绝；跨来源、畸形任务和超长查询在服务调用前拒绝。
- 固定服务端点、无凭据泄露、搜索与正文分离、空结果、HTTP 服务失败、空/无效响应、正文截取及超大服务响应拒绝；三个同时未完成的请求体也不能绕过两个收集请求的并发限制。

原有任务、文件、审核、引用与模型失败检查继续通过。所有自动测试均使用虚构数据和模拟响应，不调用真实服务。

## 浏览器边界回归（虚构服务）

运行 `node tests/research-fixture-server.mjs` 提供独立的 4176 服务；固定测试密钥，拦截所有上游请求，意外网络调用直接失败，不会访问真实 DeepSeek。页面与数据均标明虚构。

| 场景 | 实际结果 |
| --- | --- |
| 两条候选，一条 404 | 显示 1 成功、1 失败；成功正文与失败链接均保留 |
| 对失败来源点击重试 | 恢复成功，不新增重复记录 |
| 重复搜索 | 跳过已有两条链接，原正文和审核选择未改动 |
| 搜索无结果 | 明确显示空结果，现有资料数不变 |
| 慢读取时停止 | 已完成资料保留，未读取来源保持无正文，刷新可恢复 |
| 收集中替换任务 | 新任务为 0 条，后续旧结果没有写入新任务 |
| 读取期间人工排除 | 完成后仍为已排除，不被异步结果重置 |
| 没有正文的来源 | 纳入按钮禁用，不能作为报告依据 |
| 本机地址 | 界面拒绝，现有资料保留 |
| 含脚本形式的标题 | 作为普通文字显示，未产生脚本节点 |
| 模型省略待核实标签 | 页面仍附程序来源提示 |
| 刷新恢复和 TXT 导入 | 网页状态恢复正常，原有文件导入仍可保存正文和元数据；主服务原有 3 份 PDF、3 条纳入和 2 条人工标记恢复正常 |

本轮未重跑 `tests/browser.cjs` 全套旧浏览器脚本；以上是本轮实际通过浏览器控制完成的范围，不把旧版本 PDF/所有断点回归当作本轮结果。

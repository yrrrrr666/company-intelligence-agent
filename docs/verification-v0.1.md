# V0.1 验证记录

- 日期：2026-10-28
- 范围：本地交互原型；非完整 P0 验收
- 环境：Windows、Node.js 22.23.2、本机 Chrome、Playwright；桌面 1440×1080，移动端 390×844
- 数据：自主编写的虚构公司与资料，以及 example.com 链接的输入测试文本。未访问这些资料链接，无私密或第三方原始数据。

## 方法与结果

`npm test`：10 项自动检查全部通过，覆盖以下行为：

- 必填项、真实日历日期和起止日期校验。
- 拒绝可执行链接与含认证信息的 URL；保留有效查询参数，移除常见追踪参数和片段以提示重复。
- 提示日期未知、范围外、URL 重复和正文不可用。
- 报告仅使用已纳入且有正文的资料；纳入文本以快照保留，后续对象变更不会改写已生成报告。
- 模型格式及引用 ID 校验，拒绝未知、排除或缺失的来源。
- 损坏数据、重复资料 ID、不安全链接以及 Markdown 文本转义。
- 本地服务只暴露网页文件；配置响应不含密钥；拒绝非同源模型请求。
- 使用模拟 DeepSeek 响应检查成功、无效引用与无效 JSON；未调用真实模型 API。

`npm run test:browser`：完整浏览器回归通过，覆盖：

- 创建任务及错误提示、空资料状态、手动录入与非法 URL 提示。
- HTML/脚本文本安全展示，无脚本执行；URL 重复、未知日期、范围外及无正文提示。
- 纳入、排除、待核实、筛选、审核变更后的报告失效，以及刷新后恢复当前任务和选择。
- 示例任务替换前确认和取消；无正文来源不能纳入。
- 简报不含排除资料；引用可定位到保存文本；下载 Markdown 并检查范围、来源和排除行为。
- 模拟模型失败后提示、保留纳入状态、重试成功；未配置时禁用模型模式。
- 桌面和移动端无横向溢出；移动端完成生成并清空任务；减少动态效果设置下可操作；无页面脚本异常。

截图和测试导出文件位于本机 `outputs/`，不提交仓库。测试脚本：`tests/core.test.mjs`、`tests/server.test.mjs`、`tests/browser.cjs`。

## 失败案例与修复复测

首次浏览器检查发现模型选择框第二个 option 的开始标签不完整，导致配置状态更新失败。修复标签后，复测确认两种模式正确显示，未配置模型时禁用 DeepSeek；模拟模型失败与重试流程也通过。另调整了程序聚焦主内容时的边框，以及移动端清空任务入口。

# V0.5 本地资料库与关键词检索验证

- 日期：2026-10-30，北京时间。
- 目标：审核后的原始资料明确入库、跨任务复用，检索片段重新审核后进入现有生成、引用与 Markdown 导出流程。
- 分工：用户授权子智能体实现；后端、前端与独立 QA 分工，主智能体审核差异、修正集成问题、运行回归并检查实际截图。不是目标用户测试或独立事实审计。
- 环境：Windows、Node.js v22.23.2、本机 Chrome、Playwright。运行时安装在被忽略的 outputs/qa-runtime，未新增产品依赖。
- 数据：全部新增验证使用自主编写的合成文本、临时资料库和独立服务。未清空或写入用户的正式资料库，未把测试资料伪装成真实公司披露。本轮没有真实 DeepSeek 搜索、读取或生成请求，未产生这些测试调用的供应商费用。

## 实现边界

原始资料须先审核纳入、有可用正文、非虚构示例，由独立按钮保存到资料库；入库不自动证明事实。待核实资料允许明确保存并保留问题，默认不参与新检索。检索片段不能作为原始全文再次入库。来源名称、日期和核查备注实际改变时，原先纳入状态退回待审核；原值未变时保留原审核状态。

本地 JSON 文件默认 data/library.json，可通过 LIBRARY_PATH 更改位置。资料独立于浏览器当前任务，重启服务或清空任务后仍存在。写入先写临时文件、同步后原子替换，按文件路径协调同一进程的操作；损坏 JSON、异常嵌套字段或历史版本将安全报错并保留文件。限 200 份资料、每份 20 个版本、32 MiB；不支持多进程并发写入。撤回是停用检索，不是永久删除；历史版本与已加入任务、已生成报告中的快照保留。原二进制文件、之前未提取的内容不在库中。

以完整公司名的归一化结果匹配公司（NFKC、首尾和连续空格、大小写），不识别公司别名。关键词匹配使用中文相邻字和英文/数字词，不使用 embedding、向量数据库或语义重排。保存文本按段落/句末尽量切为不超过 900 个 UTF-16 字符的片段，重叠约 100；正文没有命中不因标题命中而返回。排序先依据匹配得分、兼顾不同文档，最多返回 8 个片段。可选日期仅对资料发布日期过滤，未知日期不通过启用的日期范围。

加入前通过服务端重新核对当前活动版本，过期或撤回的资料拒绝导入；导入片段精确等于对应保存文本切片，独立生成任务资料 ID、默认待审核，并保留原始出处、备注和历史警告。页面和 Markdown 可看到文档/版本/片段 ID、保存文本字符位置、检索词、检索时间。字符位置不是 PDF 内精确坐标。同一文档多段不构成独立交叉验证。

## 自动检查

最终 `node --test --test-reporter=spec tests/*.test.mjs`：**49 项通过，0 失败**。原有任务、导入、审核、网络适配与引用测试继续通过。新增测试覆盖：

- 入库资格、非演示限制、检索片段不可重复入库、来源快照及跨实例持久化。
- URL 规范化去重、文件指纹与 PDF 选页识别、版本历史；日期范围造成核查提示改变时生成新版本，主题变化但证据/提示相同时不制造重复版本。
- 中文关键词检索、无关查询、公司/日期/核查状态过滤、截取与搜索日期提示、撤回及过期版本拒绝。
- 精确片段位置、句末切分、重叠上下文、UTF-16 代理对保护；并行保存不丢资料，损坏文件及嵌套异常不覆盖原文件。
- API 来源检查、本地文件不可通过静态服务读取、不需要模型密钥、错误提示不暴露本地路径。
- 客户端拒绝伪造或不匹配切片，重置待审核，继承原文件信息/备注/历史提示；报告与导出使用不可变快照。
- 模型适配器仅发送纳入片段，不发送其余全文或排除资料；即使当前任务人工标记取消，历史核查提示仍进入模型输入。模拟响应验证有效引用和片段上下文约束，没有声称模型实际理解或遵守这些语义要求。

## 浏览器验证

原有 `npm run test:browser` 完整桌面回归通过，包含手动资料、输入安全、审核、引用、导出、刷新恢复、示例侧栏、PDF/TXT/Markdown 导入、键盘及 1120/1280/1440 布局。使用独立服务和虚构/模拟数据，不调用真实 API。

新增 `node tests/library.browser.cjs`：**20 组场景通过**。用实际表单创建合成研究任务、录入资料、审核及入库，不注入任务或浏览器存储冒充流程：

| 场景 | 结果 |
| --- | --- |
| 无任务打开空资料库、Escape 返回 | 不创建任务，返回焦点正确 |
| 未审核与已审核资料入库 | 未纳入时禁用，纳入后显式保存 |
| 保存失败、重试及重复保存 | 错误可见，任务保留，重试成功且重复不新增 |
| 改备注重新审核、原值不变 | 实际变化退回待审核，重新纳入后生成新版本；无变化保留审核 |
| 服务重启、清空/替换任务 | 已入库资料仍保留，当前任务独立 |
| 标题与正文含脚本测试文本 | 以普通文字显示，无脚本或图片节点执行 |
| 中文检索、无结果与发布日期 | 返回匹配片段，范围外/未知日期按规则排除 |
| 默认核查筛选、显式包含 | 有问题的资料默认排除，主动包含后提示仍在 |
| 片段加入、重复与生成 | 加入后待审核，相同版本同片段不能重复；纳入后规则摘录可生成 |
| 页面引用、Markdown 与历史警告 | 文档/版本/片段/位置/查询/时间/出处及备注可回溯 |
| 撤回取消、确认及旧结果 | 取消保留，确认后新检索不返回，旧搜索导入返回 409 |
| 既有报告快照 | 撤回资料不改写已生成报告 |
| 延迟搜索/片段加入遇到任务替换 | 旧响应释放后不写入新任务 |
| 实际 1120/1280/1440 视口 | 页面和详情无横向溢出，按钮可见，无页面错误 |

结果摘要：pageErrors=[]，externalRequests=[]。输出在被 Git 忽略的 outputs/v0.5-library/，包括 browser-summary.json、合成资料 Markdown 与六张截图。最终截图等待真实短时提示消失后拍摄；主智能体查看 1280 检索与 1440 简报，并在前轮查看 1120，QA 也检查最终 1120/1440。没有把历史截图当作本轮验证。

## 质量限制与待办

关键词可能匹配宽泛或重叠上下文；左侧预览显示片段开头约 180 字，规则摘录仍保留每来源前 500 字，不会自动把最相关句子移到摘要前面。长背景段落的合成案例暴露了这一限制。它不是语义问答效果验证，也不能推出覆盖率、事实准确率或研究效率提升。向量检索、重排、真实多公司固定样本、口径完整性、需求访谈和费用/人工对照仍待完成。

原文保存上限仍为 12,000 字；检索不能恢复之前截掉或未提取的文字。业务期间没有独立结构化字段，仍需对照正文核查。暂无任务历史、云端同步、永久删除、资料库备份/恢复界面和多进程写协调。

界面沿用现有设计体系，无新栅格资源。机械检测运行一次，存在继有容器 padding、颜色/字号体系建议及对话框阴影警告；不把它记为零警告通过。新增顶栏选中颜色已改用现有变量。独立 finish reviewer 重开全部六张最终截图后给出 **ship**，未发现本次扩展的实质界面缺陷；范围仅为继有设计下的本次扩展，没有新 QUALITY BAR 卡片或旧 seed 来源的再次验证。文档子智能体两次遇到模型容量限制，主智能体按 documenter fallback 核对并保留 DESIGN.md/sidecar，追加局部 surface 记录，没有顺带修理已有体系差异。

交付前检查：变更及未忽略新增文件的凭据模式扫描无命中，未包含 data/、outputs/、node_modules/ 或私密环境文件；未读取或提交原始研究资料。正式本地服务启动于 http://127.0.0.1:4173，首页及新客户端模块均返回 200；此健康检查未发起搜索或模型调用。
